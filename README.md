# XOLIRX VPN — iOS

Монохромный менеджер подписок для iPhone в стиле десктопной версии 2.1:
импорт подписки, список серверов с флагами и реальным пингом, экспорт
sing-box-конфига и запуск установленного VPN-клиента одной кнопкой.

> Честно: `.ipa` нельзя собрать на Windows. Приложение компилируется только
> Xcode-тулчейном на macOS. Но macOS иметь не обязательно — есть облачная
> сборка на GitHub Actions, которая выдаёт готовый `.ipa` (см. ниже).

---

## Вариант 1. Облако, без своего Mac (рекомендую)

1. Создайте на GitHub пустой репозиторий, например `xolirx-ios`.
2. Загрузите в него **содержимое этой папки** (`ios/`), включая скрытую
   папку `.github`.
3. Откройте вкладку **Actions → build-ipa → Run workflow**.
4. Через 3–5 минут скачайте артефакт **XOLIRX-unsigned-ipa** —
   внутри `XOLIRX-unsigned.ipa`.
5. Установите его на iPhone через **Sideloadly** или **AltStore**:
   подключите телефон, перетащите `.ipa`, войдите своим Apple ID —
   утилита подпишет приложение локально.
   Бесплатный Apple ID: подпись живёт 7 дней, потом повторить.
   Платный аккаунт разработчика: до года, без переподписи.

Неподписанный IPA нельзя просто «закинуть» в телефон — iOS требует подпись,
поэтому шаг 5 обязателен.

## Вариант 2. Свой Mac

Нужны macOS 13+, Xcode 15+, XcodeGen.

```bash
brew install xcodegen
cd ios
xcodegen generate
open Xolirx.xcodeproj
```

В Xcode: выберите target `Xolirx` → **Signing & Capabilities** → свой Team
и уникальный Bundle Identifier (например, `ru.вашеимя.xolirx`). Подключите
iPhone и нажмите **Run**.

Сборка IPA одной командой:

```bash
DEVELOPMENT_TEAM=XXXXXXXXXX ./build-ipa.sh
# результат: build/ipa/XOLIRX.ipa
```

Либо в Xcode: **Product → Archive → Distribute App → Development/Ad Hoc**.

## Что уже работает

- Импорт ссылки-подписки (base64-список) и отдельных ключей
  `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`.
- Определение страны и флага: эмодзи, `[US]`, `NL-01`, `FI15`, `es7`,
  английские/русские названия и города. Мусорные теги вроде `AUTO NODE`
  страной не считаются.
- Реальный TCP-пинг до каждого узла (без выдуманных значений).
- Выбор сервера, фильтр по странам, хранение на устройстве.
- Тёмная/светлая/системная тема, чёрно-белый фон и обесцвеченные флаги.
- Экспорт sing-box JSON в буфер обмена.
- Кнопка «Открыть в VPN-клиенте»: `sing-box`, `Streisand`, `Shadowrocket`
  по их URL-схемам; если клиента нет — конфиг копируется.
- Автообновление подписок: 1/3/6/12/24 ч или выключено.
- Иконка приложения в монохромной серифной стилистике и privacy manifest.

## Ограничения iOS

- Подписки только по `https://`: ATS не пропускает незашифрованный `http://`,
  приложение сразу подсказывает это в поле ввода.
- Для установки нужна подпись (Sideloadly/AltStore или Mac с Xcode).

## Чего пока нет

- Собственного туннеля внутри приложения. На iOS для этого нужен
  `NetworkExtension` + встроенное ядро (libbox/xray), отдельный target,
  платный Apple Developer аккаунт и entitlement
  `com.apple.developer.networking.networkextension`.
  Заготовки и порядок действий — в `Tunnel/README.md`.
- App Store-подписи (для App Store нужен платный аккаунт и ревью).

## Структура

```
ios/
  project.yml                 — проект для XcodeGen
  build-ipa.sh                — сборка/экспорт IPA на macOS
  ExportOptions.plist         — параметры экспорта
  .github/workflows/ios.yml   — облачная сборка IPA
  Xolirx/
    App/XolirxApp.swift
    Core/                     — модели, парсер, страна, пинг, конфиг, стор
    Design/Theme.swift        — палитра и компоненты
    Screens/                  — главный экран, серверы, настройки, добавление
    Resources/                — фон и аватар
    Assets.xcassets/          — иконка приложения
    Info.plist
  Tunnel/                     — заготовка для NetworkExtension (этап 2)
```

## Приватность

Приложение не отправляет данные никуда, кроме запроса самой подписки.
Подписки, серверы и настройки лежат в `UserDefaults` на устройстве.
Журналов и телеметрии нет.
